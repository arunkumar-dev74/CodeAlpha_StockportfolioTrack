# Stock Portfolio Tracker

## About
A Python-based Stock Portfolio Tracker that helps users
manage stock holdings and calculate investment performance.

## Features
- Add Stocks
- View Portfolio
- Update Stock Details
- Delete Stocks
- Search Stocks
- Calculate Investment
- Calculate Profit and Loss
- Portfolio Dashboard
- Investment Charts
- SQLite Database

## Technologies
- Python
- SQLite
- Streamlit
- Pandas
- Matplotlib

## Installation

Install the required libraries:

pip install -r requirements.txt

## Run Application

streamlit run app.py

## Run Tests

python -m unittest discover -s tests -v

## Note
Stock prices are manually entered by the user.
This project does not provide live market prices.
